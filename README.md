# ももヨガ — 岡山のヨガ先生マッチング

4つの質問に答えると、岡山・倉敷のヨガの先生が相性の高い順に並ぶマッチングアプリのデモです。

**公開ページ:** https://tsubasagit.github.io/momo-yoga/

## できること

- **生徒**：相性診断 → 先生をさがす（絞り込み・並べ替え）→ お気に入り → 体験レッスンの申し込み
- **講師**：届いた申し込みの承認／お断り、プロフィールの編集（生徒の画面と相性にすぐ反映）

画面右上の「生徒／講師」で切り替えます。

## しくみ

- `index.html` 1枚で動きます（ビルド不要・外部ライブラリなし）
- 保存はブラウザの localStorage だけ。先生・生徒はすべて架空のデータです
- 仕様は [SERVICE_SPEC.md](SERVICE_SPEC.md)
